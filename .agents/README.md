# Hướng dẫn sử dụng thư mục agent

Thư mục này chứa workflow và mẫu bàn giao; không tự kích hoạt quyền thực thi. Điểm vào chính là `../AGENTS.md`.

- [workflows.md](workflows.md): quy trình đọc, lập kế hoạch, triển khai sau phê duyệt và review.
- [handoff-template.md](handoff-template.md): mẫu để agent sau tiếp tục đúng phạm vi.

Không thêm skill/sub-agent tự động khi chưa cần. Nếu về sau tạo SKILL.md thực sự, áp dụng quy trình tạo skill phù hợp và ghi cách sử dụng rõ ràng.
